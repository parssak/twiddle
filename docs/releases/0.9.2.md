# Twiddle 0.9.2

- Fixes filtering dropping out when Spotify plays audio through a helper process, which can happen on certain tracks or when switching playback modes.
- Follows audio helpers for selected apps, including helpers that start after Twiddle, without resetting the filter.

Requires macOS 26 or later on Apple silicon. Twiddle 0.9.1 users can update in the app. Users on 0.9 or earlier need one manual download to move to the current update feed.
