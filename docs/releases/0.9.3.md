# Twiddle 0.9.3

- Automatically applies your saved preset while macOS `say` speaks, with no trigger-app selection required. This works with announcements from Codex, Terminal, and scripts.
- Restores the previous amount after speech ends. Silent streams and speech written only to a file do not hold the preset.
- Includes the Spotify audio-helper capture fix from 0.9.2.

Requires macOS 26 or later on Apple silicon. Twiddle 0.9.1 users can update in the app. Users on 0.9 or earlier need one manual download to move to the current update feed.
