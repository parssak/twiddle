# Twiddle 0.9.4

- Fixes filtering going silent in Arc when several Arc helpers share a bundle ID and macOS attached the wrong one.
- Follows helpers that start, exit, or restart while Twiddle is filtering, without resetting the filter.
- Includes the `say` auto-apply and Spotify audio-helper fixes from 0.9.3.

Requires macOS 26 or later on Apple silicon. Twiddle 0.9.1 users can update in the app. Users on 0.9 or earlier need one manual download to move to the current update feed.
